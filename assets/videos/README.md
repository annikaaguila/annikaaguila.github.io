Since you've got plenty on @annika_film, feel free to mix it up — the final
cut, a behind-the-scenes clip, a favorite alt take, whatever tells the
story best. Just keep the exact filenames above so the site picks them up.

Want more than 3 slots per project, or a project split into its own section
entirely? Ask and I'll add it.

**Format:** `.mp4` (H.264 video / AAC audio) plays everywhere.

**Size:** GitHub hard-blocks any single file over 100MB, and warns above 50MB.
Compress with Handbrake or similar, or export at a lower bitrate, to keep
each clip well under that. If a film is longer or you want higher quality,
upload it to YouTube/Vimeo instead and swap in an embed — ask and I can
wire that up.
